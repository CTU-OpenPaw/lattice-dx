# Solutions

Lưu từng ứng dụng nghiệp vụ trong thư mục riêng: README mô tả bài toán, mô hình dữ liệu, workflow, cấu hình xuất từ nền low-code và dữ liệu khởi tạo có nguồn/giấy phép rõ ràng.

Bản 0.1 chưa lựa chọn bài toán nghiệp vụ. Demo kiểm tra kết nối hiện nằm trong các app, không giả lập một ứng dụng nghiệp vụ hoàn chỉnh.
