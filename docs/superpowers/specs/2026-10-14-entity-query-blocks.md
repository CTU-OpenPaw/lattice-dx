## Typed entity query

POST /v1/entities/query, data:read, read-only so no Idempotency-Key required. Strict body {schemaId,schemaVersion,filters?,sort?,limit?,offset?}. Required published schemaVersion pins types; only matching schema/version active entities returned. Filters is AND list at most10, each exact {field,operator,value?}. operator eq/ne/gt/gte/lt/lte/contains/exists. Field declared in publication; value validated against declared type (not requiredness). exists has no value; contains text only; order operators integer/decimal/date only; eq/ne all scalars. Missing attribute never matches comparison including ne. Decimal compared/order NUMERIC with exact precision; integer numeric; date ISO lexical; boolean no order. Reject malicious/reserved/unknown fields or wrong value types400. Publication missing404.

Sort optional {field,direction:'asc'|'desc'}, declared field only; default created_at DESC,id DESC. Nulls last, deterministic id tie-break. limit1..100 default50, offset0..safe max default0; existing Page response. Query JSON and scalar value bounds use existing16KiB. ACL filtered in SQL before LIMIT/OFFSET. No raw SQL/script/regex, no generic nested conditions in query v1. Repository query?(scope,input):Promise<Page<Entity>>, production implements. Transaction-free read one validated publication + parameterized entity query; immutable publication prevents schema change during read. Add appropriate multicolumn schema scope index.

## Builtin data block catalog and execution

GET /v1/blocks returns {items} only available entries authorized by caller. POST /v1/blocks/:id/run body {version:1,input} -> {blockId,version:1,status:'succeeded',result}. IDs entities.create/read/query/update/archive/link/unlink. Descriptor {id,version:1,title,requiredRole,inputSchema,outputSchema,mutation:boolean}; declarative JSON schema includes actual required nested objects/bounds/types, no client executable code or dependencies. Registry server-side immutable supportedIDs, no plugin upload arbitrary handlers. Old /v1/actions unchanged.

Input exactly corresponding entity API plus id for existing entity operations. entities.query input typed query; read {id}. create/update attributes scalar object validated repository. Mutations require valid Idempotency-Key, forwarded unchanged to same repository operations so REST/block same actor/org/operation/key returns same receipt. All repository errors/status preserved. Role data:read or data:write checked before execute; actor/org from verified JWT only; never permit body authority.
